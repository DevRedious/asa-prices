Utiliser ces données

Le fichier est statique, servi par CDN, sans clé ni authentification : appelez-le autant que nécessaire.

const data = await fetch('https://devredious.github.io/asa-prices/asa-prices.json').then(r => r.json());
const astraeos = data.products.find(p => p.name.includes('Astraeos'));
console.log(astraeos.best_price_eur, astraeos.best_store);

Chaque produit porte le détail de ses offres par boutique et par marché, le meilleur prix converti en euros, la remise en cours avec sa date de fin, et la date de sortie. Les instants sont en UTC au format ISO 8601 : convertissez-les dans le fuseau de votre lecteur. README · llms.txt

Questions fréquentes

Les prix sont-ils les mêmes sur les trois boutiques ?

Oui pour la quasi-totalité du catalogue : l'éditeur dépose la même grille sur les trois plateformes et coordonne ses soldes. Les exceptions sont les éditions groupées, dont chaque boutique décide du contenu et de la remise — l'écart peut y atteindre plusieurs dizaines d'euros. Les promotions ne se terminent pas non plus aux mêmes dates.

À quelle fréquence est-ce mis à jour ?

Chaque jour. Le jeu de données n'est réécrit que lorsqu'un prix a réellement changé, si bien que l'historique du dépôt est un historique de prix.

Données relevées sur les boutiques publiques de Sony, Microsoft et Valve. Ce projet n'est affilié ni à ces sociétés ni à Studio Wildcard. Les marques citées appartiennent à leurs propriétaires respectifs.
