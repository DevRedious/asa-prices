Using this data

The file is static and CDN-served, with no key and no authentication: call it as often as you need.

const data = await fetch('https://devredious.github.io/asa-prices/asa-prices.json').then(r => r.json());
const astraeos = data.products.find(p => p.name.includes('Astraeos'));
console.log(astraeos.best_price_eur, astraeos.best_store);

Every product carries its offers per store and per market, the best price converted to euros, the running discount with its end date, and the release date. All instants are UTC in ISO 8601: render them in your reader's own time zone. README · llms.txt

Frequently asked questions

Are prices identical across the three stores?

For almost the whole catalogue, yes: the publisher files the same price grid on all three platforms and coordinates its sales. The exceptions are the bundles, whose contents and discount each store decides on its own — gaps there can reach tens of euros. Sales also do not end on the same dates.

How often is this updated?

Every day. The dataset is only rewritten when a price actually changed, which makes the repository's history a price history.
